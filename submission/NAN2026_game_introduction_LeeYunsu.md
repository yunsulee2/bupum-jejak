# 1. 이 게임이 시작된 질문

## 처음에는 스마트폰을 조립하고 싶었습니다

처음 떠올린 것은 스마트폰 제작 시뮬레이션이었습니다. 수많은 부품을 레고처럼 설명서대로 맞춰 완성하면 실무에도 도움이 되지 않을까 생각했습니다. 하지만 곧 문제가 보였습니다. 스마트폰은 내부 부품 수가 너무 많고, 사용자가 실제로 분해·조립할 기회도 드뭅니다. 화려한 장면은 만들 수 있어도, 플레이 뒤 현실에서 써먹기 어려웠습니다.

그래서 질문을 바꿨습니다.

> “사람들이 실제로 직접 맞추지만, 막상 무엇을 사야 하고 어디에 끼워야 하는지는 잘 모르는 제품은 무엇일까?”

그 답이 게이밍 컴퓨터였습니다. 사람들은 흔히 “컴퓨터를 맞춘다”고 말합니다. 그러나 실제로는 CPU 소켓, 메모리 슬롯, M.2 규격, 전원 용량, 그래픽카드 크기, 케이블 경로를 동시에 판단해야 합니다. 조립은 손의 문제가 아니라 **구매와 호환성 판단의 문제**였습니다.

## 컴퓨터를 만들고 나니 더 큰 문제가 보였습니다

PC 한 대를 완성한 뒤에도 질문은 끝나지 않았습니다. 컴퓨터만 잘 만드는 시뮬레이터가 아니라, 집에서 반복되는 “비슷해 보여서 잘못 사는 문제” 전체를 다룰 수 있지 않을까 생각했습니다.

처음에는 전구 교체를 떠올렸습니다. 하지만 한국의 오래된 주거 공간에서 더 익숙한 것은 직관 형광등입니다. 그래서 전구 화면과 절차를 모두 버리고, 램프 코드·길이·G13 핀·소비전력·안정기를 확인하는 형광등 실습으로 다시 만들었습니다.

다음 후보는 싱크대 수리였습니다. 그러나 전문 기사에게 맡겨야 할 범위까지 게임이 무리하게 안내하면 위험합니다. 대신 사용자가 집에서 실제로 교체하는 샤워기 필터를 선택했습니다. 마지막으로 비슷한 판재와 좌우 레일 때문에 설명서를 보고도 자주 틀리는 3단 서랍장을 추가했습니다.

이 선택 과정에서 콘텐츠를 고르는 기준이 생겼습니다.

- 집에서 일반 사용자가 실제로 시도하는가
- 비슷한 부품 때문에 구매·방향 실수가 발생하는가
- 잘못했을 때 이유를 설명할 수 있는가
- 전문가에게 맡겨야 할 경계를 게임 안에서 분명히 말할 수 있는가

`부품제작`은 이 네 기준을 통과한 문제만 다룹니다.

## 해결하려는 핵심 문제

기존 설명서는 정답 순서를 보여줍니다. 하지만 사용자가 현실에서 막히는 순간은 순서를 읽기 전후에 있습니다.

- 내 제품의 정확한 모델과 규격을 모릅니다.
- 이름과 외형이 비슷한 부품을 잘못 삽니다.
- 앞뒤·좌우·회전 방향을 혼동합니다.
- 설치가 끝나면 검증 없이 바로 사용합니다.
- 위험한 상황에서도 어디서 멈춰야 하는지 모릅니다.

그래서 이 게임은 “클릭하면 다음 단계”가 아니라 다음 여섯 단계로 설계했습니다.

**관찰 → 비교 → 선택 → 직접 조작 → 작동 검증 → 실수 원인 회고**

조립을 시작하기 전에 이미 게임은 시작됩니다. 마지막 부품을 놓은 뒤에도 게임은 끝나지 않습니다.

# 2. 게임 개요와 플레이 경험

## 게임의 한 문장 약속

> 현실에서 돈과 시간을 쓰기 전에, 잘못 사고 잘못 끼우고 다시 고치는 과정을 안전하게 연습한다.

플레이어는 네 개의 생활 실습 중 하나를 선택합니다. 각 실습은 같은 세계관과 조작 언어를 공유하지만, 해결해야 하는 판단은 다릅니다.

| 실습 | 플레이어가 해결하는 실제 문제 | 핵심 상호작용 | 완료 조건 |
|---|---|---|---|
| 게이밍 컴퓨터 조립 | 예산 안에서 호환 제품을 사고 올바른 슬롯·방향에 설치 | 제품 비교, 3D 드래그, 카메라 조작 | 14단계 설치와 첫 부팅 자체 검사 |
| 형광등 교체 진단 | 비슷한 직관 램프에서 맞는 코드·핀·안정기 제품 찾기 | 현장 조사, 규격 비교, 90° 회전 | 안전 준비, 점등·소음·떨림 검사, 분리배출 |
| 샤워기 필터 교체 | 본체 세대와 장착 위치에 맞는 리필 구분 | 오염 조사, 360° 캡 회전, 필터 드래그 | O링 밀폐와 누수·수압·물줄기 검사 |
| 3단 서랍장 조립 | 판재 안팎, 캠락 방향, 좌우 레일, 직각 구분 | 방향 판정, 자석식 스냅, 대각선 비교 | 세 서랍 작동과 전도 방지 계획 검증 |

## 공통 게임 루프

### 1) 현장에서 단서를 찾습니다

형광등에는 램프 인쇄와 안정기 방식이 있고, 샤워기에는 본체 세대와 필터 위치가 있습니다. 플레이어는 제품 목록을 보기 전에 현재 상황을 먼저 조사합니다. 이는 현실에서 사진 한 장만 보고 부품을 주문하는 실수를 게임 안에서 재현합니다.

### 2) 닮은 후보 사이에서 비교합니다

정답만 진열하지 않습니다. 핀은 같지만 길이가 다르거나, 브랜드는 같지만 세대가 다르거나, 외형은 같지만 장착 위치가 다른 후보가 함께 나옵니다. 오답을 고르면 단순히 “틀렸습니다”라고 하지 않고 어떤 필드가 맞지 않는지 항목별로 보여줍니다.

### 3) 사용자가 직접 움직입니다

자동 설치 버튼 대신 부품을 잡아 목표 위치까지 끌어야 합니다. 정답 위치는 홀로그램·윤곽·거리 문장으로 안내하지만, 마지막 이동은 플레이어가 합니다. 위치가 멀거나 방향이 틀리면 부품은 안전하게 돌아오고 다음 시도에 필요한 힌트를 줍니다.

### 4) 완성 뒤 작동을 검증합니다

PC는 팬 9개, RGB, 모니터 첫 부팅을 확인합니다. 형광등은 떨림과 이상 소음, 샤워기는 누수와 수압, 서랍장은 걸림과 쏠림을 검사합니다. 현실의 “조립은 됐는데 제대로 작동하지 않는” 순간까지 게임 범위에 넣었습니다.

## 실습 1. 게이밍 컴퓨터 조립

구매 단계에는 12개 카테고리와 28개의 실제 제품 후보가 있습니다. 책상·의자·모니터부터 CPU, SSD, RAM, 쿨러, 전원공급장치, 메인보드, GPU, 케이블까지 가격을 합산합니다. GPU는 RTX 4070 계열을 포함한 여섯 가지 후보를 비교할 수 있습니다.

중요한 점은 구매 결과가 텍스트에서 끝나지 않는다는 것입니다. 선택한 SKU에 따라 색, 형태, 팬 수와 부품 변형이 달라지고, 조립 완료 후 방에도 같은 구성이 반영됩니다.

![실제품 사진과 가격, 총 견적을 함께 보여주는 PC 구매 화면](https://raw.githubusercontent.com/yunsulee2/bupum-jejak/main/qa/shop-real-products.png)

*“무엇을 샀는가”가 3D 조립 부품과 최종 방의 모습으로 이어집니다.*

조립은 가구·모니터 6단계와 PC 핵심 부품 8단계, 총 14단계입니다. 사용자는 부품을 빛나는 장착 영역에 직접 놓고, 카메라를 돌려 슬롯과 방향을 확인합니다. 팬은 조립 중에도 계속 회전해 케이스가 빈 상자가 아니라 작동하는 제품처럼 느껴지게 했습니다.

*강화유리 케이스 안쪽의 목표 위치, 현재 부품, 다음 이동 방향을 동시에 읽을 수 있게 설계했습니다.*

완성하면 책상·모니터·의자·PC가 한 방에 배치됩니다. 빈 공간을 끌거나 휠을 사용해 결과 화면에서도 자신의 구성을 여러 각도에서 볼 수 있습니다.

## 실습 2. 형광등 교체 진단

“전구를 끼운다”는 단순 동작 대신 한국 주거 환경에서 흔히 생기는 오구매를 다룹니다. 플레이어는 기존 램프에서 코드, 길이, G13 핀, 소비전력, 색온도와 안정기 방식을 찾습니다. 유사 제품을 잘못 선택하면 통과하지 못한 항목을 바로 비교합니다.

![유사 형광램프를 잘못 골랐을 때 규격별 원인을 보여주는 화면](https://raw.githubusercontent.com/yunsulee2/bupum-jejak/main/qa/fluorescent-03-wrong-product-feedback.png)

전원을 차단하고 파손 여부를 확인한 뒤 양끝을 잡아 90° 회전해 분리·설치합니다. 점등 후에는 밝기만 보지 않고 떨림과 이상 소음을 검사하며, 폐램프는 종량제 봉투가 아니라 전용 수거함으로 보내야 완료됩니다.

## 실습 3. 샤워기 필터 교체

같은 브랜드 안에도 일반형·시그니처·여행용, 서로 다른 세대와 장착 위치가 있습니다. 플레이어는 투명창의 오염과 본체 정보를 조사한 뒤 호환 리필을 고릅니다. 수전을 잠그고 잔압을 제거해야만 캡을 열 수 있습니다.

필터는 버튼 한 번으로 들어가지 않습니다. 새 필터를 직접 끌어 투명 바디 중앙에 수직으로 놓습니다. O링을 홈에 안착시키고 캡을 다시 체결한 뒤 물을 흘려보내 누수·수압·물줄기를 모두 확인합니다.

![새 필터 설치 뒤 누수와 수압을 검증한 욕실 결과 화면](https://raw.githubusercontent.com/yunsulee2/bupum-jejak/main/qa/shower-07-completion-bathroom.png)

## 실습 4. 3단 서랍장 조립

서랍장은 부품을 “대충 맞는 위치”에 놓는 것만으로 완성되지 않습니다. 판재 마감면과 구멍 면, 캠락 화살표, 좌우 레일, 앞뒤 방향을 구분해야 합니다. 자석식 스냅은 목표에 가까워질수록 흡착감을 주지만, 방향이 틀리면 결합되지 않습니다.

뒤판을 고정하기 전에는 두 대각선 길이를 비교해 직각을 맞추고, 벽 재질에 맞는 전도 방지 계획을 선택합니다. 마지막에는 서랍 세 칸을 각각 열고 닫아 걸림·틈·쏠림을 확인합니다.

![조립과 수평, 작동 검증을 마친 3단 서랍장](https://raw.githubusercontent.com/yunsulee2/bupum-jejak/main/qa/drawer-09-completion.png)

# 3. 플레이 방법

## 권장 환경

- 데스크톱 Chrome 또는 Edge 최신 버전
- 1280×720 이상 화면과 마우스 권장
- Safari 최신 버전과 모바일 화면도 지원
- 별도 회원가입, 설치, 결제, API 키 불필요

기기 성능과 화면 조건에 따라 렌더링 품질을 조정하며, 모바일에서는 경량 3D 모델을 사용합니다. WebGL이 차단된 브라우저나 사내 보안 환경에서는 3D 화면이 표시되지 않을 수 있습니다.

## 공통 조작

| 입력 | 동작 |
|---|---|
| 왼쪽 클릭 | 메뉴·제품·단서 선택, 부품 잡기 |
| 왼쪽 클릭한 채 이동 | 부품 드래그, 회전 다이얼 조작 |
| 3D 빈 공간 끌기 | 시점 회전 |
| 마우스 휠 | 확대·축소 |
| 우클릭 끌기 | 시점 평행 이동 |

## 게이밍 컴퓨터 빠른 시작

1. 메인 화면에서 **게이밍 컴퓨터 조립**을 선택합니다.
2. 왼쪽 구매 목록에서 12개 카테고리를 확인하고 각 제품을 선택합니다.
3. 오른쪽에서 총 견적과 3D 조립실 준비 상태를 확인합니다.
4. **구매 확정하고 조립하기**를 누릅니다.
5. 왼쪽 보관함과 오른쪽 가이드를 보고 현재 부품을 선택합니다.
6. 부품을 빛나는 목표 영역까지 끌어 놓습니다.
7. 화면의 거리·방향 피드백을 읽고 다시 시도합니다.
8. 14단계를 마친 뒤 전원 인가 자체 검사를 확인합니다.
9. 완성된 방에서 카메라를 움직여 구매 구성이 반영됐는지 확인합니다.

## 생활 교체 실습 빠른 시작

형광등과 샤워기 실습은 오른쪽 안내 패널의 조사 항목을 먼저 완료합니다. 모든 단서를 찾기 전에는 구매 판단이 끝나지 않습니다. 제품 선택 뒤에는 안전 준비, 분리, 직접 설치, 작동 검증 순서로 진행합니다.

서랍장은 키트와 부품표를 확인한 뒤 3D 캔버스에서 판재를 직접 이동합니다. 현재 목표가 화면을 가리면 모바일과 작은 화면에서 안내 패널을 접어 작업 공간을 넓힐 수 있습니다.

## 실패는 벌점이 아니라 다음 행동입니다

- PC 부품을 잘못 놓으면 원위치로 돌아가고 다음 이동 방향을 알려줍니다.
- 호환되지 않는 제품을 고르면 불일치 규격을 항목별로 표시합니다.
- 전원·수전 차단 같은 안전 조건을 건너뛰면 다음 단계가 잠깁니다.
- 파손, 지속 누수, 배선 수리, 불명확한 벽 재질은 전문가 확인 범위로 안내합니다.

PC 점수는 기본 100점에서 잘못 놓은 횟수당 8점이 차감되며 최저 60점입니다. 생활 실습 결과에는 구매 실수, 안전 절차, 호환 제품과 최종 작동 상태가 기록됩니다. 빠른 손보다 **실수의 이유를 이해하고 줄이는 것**이 더 좋은 결과를 만듭니다.

# 4. 실행 방법과 완성도 증거

## 방법 A. 심사용 웹 실행

1. [부품제작 웹 게임](https://yunsulee2.github.io/bupum-jejak/)에 접속합니다.
2. 첫 화면에서 원하는 실습을 선택합니다.
3. 별도 설치 없이 즉시 플레이합니다.

GitHub Pages에 배포된 빌드는 제출 저장소의 `main` 브랜치에서 자동 생성됩니다.

## 방법 B. 소스에서 실행

다음 명령을 순서대로 실행합니다.

1. `git clone https://github.com/yunsulee2/bupum-jejak.git`
2. `cd bupum-jejak`
3. `npm install`
4. `npm run dev`
5. 브라우저에서 `http://127.0.0.1:5173` 접속

프로덕션 전체 검증은 `npm run verify`로 실행합니다. 이 명령은 프로덕션 빌드, 성능 예산 검사, 자동 테스트를 연속 실행합니다.

처음에는 모든 3D 코드와 모델을 첫 화면에서 불러왔습니다. 실제 브라우저 성능을 측정한 뒤 실습을 선택할 때만 필요한 모듈을 내려받도록 바꾸고, Neural4D 원본은 조립 노드를 유지한 채 Meshopt로 압축했습니다. 작은 글씨는 키웠지만 3D 공간을 가리지 않도록 패널 내부 스크롤과 접기 방식을 사용했습니다.

제출 직전에는 구매 견적이 그리드 높이를 밀어 버튼이 화면 아래로 사라지는 문제도 발견했습니다. 1024×640부터 1440×900까지 실제 버튼 좌표를 측정하고, 구매 목록만 스크롤되도록 그리드 행을 수정한 뒤 회귀 테스트를 추가했습니다. 마지막 날까지 “보여주는 데모”가 아니라 “끝까지 플레이되는 게임”을 만들고자 했습니다.

## 안전과 현재 범위

이 작품은 실제 작업을 대체하는 자격 교육이 아니라 구매와 조립 전에 판단 과정을 연습하는 게임형 프로토타입입니다.

- 형광등은 램프 교체만 다루며 소켓·안정기·배선 수리는 안내하지 않습니다.
- 샤워기는 교체형 리필과 O링 점검만 다루며 깨진 케이스·고착·지속 누수는 전문가 범위입니다.
- 서랍장은 벽 재질을 확인할 수 없으면 임의의 앵커 사용을 정답으로 처리하지 않습니다.
- PC 가격은 조사 기준일의 참고값이며 실제 판매가·재고와 다를 수 있습니다.

이 경계는 콘텐츠 부족을 감추기 위한 문장이 아닙니다. 생활 문제를 다루는 게임이라면 “할 수 있는 것”만큼 “멈춰야 하는 것”도 가르쳐야 한다고 판단했습니다.

## 개발자의 마지막 말

저는 혼자 참가하지만 혼자 생각하지는 않았습니다. AI에게 계속 질문했고, 나온 결과를 실제 화면에서 보고 다시 문제를 제기했습니다. 컴퓨터가 공중에서 조립되는 것처럼 보이면 좌표를 고쳤고, 케이블이 어색하면 설치 전후 메시를 분리했으며, 글자가 작으면 3D 공간을 지키면서 읽을 수 있는 구조를 다시 만들었습니다. 전구라는 제 첫 표현이 한국의 생활 경험과 맞지 않을 때는 이미 만든 기능을 버리고 형광등으로 바꿨습니다.

그 과정에서 제가 만들고 싶었던 것은 설명서를 대신 읽어주는 게임이 아니라는 점이 분명해졌습니다.

이 작품이 본선에서 더 큰 주제와 만난다면, 저는 48시간 동안 기능 수를 늘리는 사람이 아니라 사용자의 실수를 관찰하고 AI에게 정확한 다음 문제를 던지는 디렉터가 되겠습니다.
