## 게임이 해결하려는 문제

제품 조립에서 가장 어려운 지점은 나사를 돌리는 행동 자체보다 **내 제품을 정확히 알아보고, 맞는 부품을 사고, 올바른 순서와 방향을 판단하는 과정**입니다. 비슷해 보이는 부품을 잘못 구매하거나 장착 방향을 뒤집으면 작업은 중단되고, 전기·누수·전도 같은 안전 문제로 이어질 수 있습니다.

기존 설명서는 정답 순서를 보여주지만 사용자가 실제로 하는 실수와 그 원인을 충분히 설명하지 않습니다. `부품제작`은 제품마다 다른 판단 과정을 게임 규칙으로 바꿉니다.

1. 현장과 기존 제품에서 단서를 찾습니다.
2. 비슷한 후보를 비교하고 호환 제품을 선택합니다.
3. 3D 부품을 직접 끌거나 회전해 장착합니다.
4. 잘못된 선택에는 어떤 조건이 맞지 않는지 즉시 알려줍니다.
5. 완성 후 작동·누수·정렬·안전 상태를 검증합니다.

## 플레이 목표

네 개의 생활 조립 실습 중 하나를 골라 조사, 구매 또는 키트 선택, 직접 조작, 최종 검증까지 완료합니다. 빠르게 누르는 것보다 **규격·방향·순서를 이해하고 실수를 줄이는 것**이 높은 성과로 이어집니다.

| 실습 | 핵심 문제 | 플레이 완료 조건 |
|---|---|---|
| 게이밍 컴퓨터 조립 | 실제 제품 비교 구매와 14단계 장착 | 가구·모니터·PC 부품을 순서대로 설치하고 첫 부팅 자체 검사 통과 |
| 형광등 교체 진단 | 비슷한 직관 램프의 규격·안정기 구분 | 안전 절차, 90° 교체, 점등 검사, 폐형광등 분리배출 완료 |
| 샤워기 필터 교체 | 본체 세대·리필 계열·O링 호환 판별 | 수전 잠금, 필터 삽입, O링 밀폐, 누수·수압 시험 통과 |
| 3단 서랍장 조립 | 비슷한 판재·좌우 레일·캠락 방향 구분 | 프레임과 서랍을 조립하고 직각·전도 방지·열림 시험 통과 |

## 핵심 게임 흐름

### 1. 실습 선택

메인 화면에서 네 개의 실습 중 하나를 선택합니다. 선택하기 전에는 무거운 3D 엔진과 모델을 내려받지 않아 첫 화면에 빠르게 진입합니다.

### 2. 조사와 선택

형광등과 샤워기 필터는 먼저 기존 제품의 인쇄, 크기, 연결 방식, 모델 세대와 같은 단서를 조사합니다. 컴퓨터는 실제 판매 제품의 사양과 가격을 비교해 예산을 구성하고, 서랍장은 서로 다른 키트의 난이도와 레일 방식을 고릅니다.

### 3. 직접 조작

컴퓨터 부품과 샤워기 필터는 마우스로 잡아 빛나는 장착 위치까지 직접 끌어 놓습니다. 형광등과 샤워기 캡은 마우스로 원을 그려 필요한 각도만큼 돌립니다. 서랍장 판재는 위치뿐 아니라 앞뒤·좌우 방향까지 맞춰야 스냅됩니다.

### 4. 실패 원인 피드백

정답 위치에서 멀리 놓으면 부품이 원래 자리로 돌아가고 다음 이동 방향을 알려줍니다. 호환되지 않는 상품은 길이, 핀, 전력, 세대, 필터 위치 등 틀린 조건을 항목별로 표시합니다. 위험한 행동은 다음 단계로 진행되지 않습니다.

### 5. 완성 검증

완성은 마지막 부품을 놓는 순간이 아닙니다. PC는 팬 9개와 RGB 조명, 모니터 첫 부팅을 확인합니다. 형광등은 떨림과 이상 소음, 샤워기는 누수와 수압, 서랍장은 걸림과 쏠림을 검사해야 끝납니다.

## 조작 방법

### 공통

| 조작 | 기능 |
|---|---|
| 왼쪽 클릭 | 버튼 선택, 단서 조사, 부품 잡기 |
| 왼쪽 클릭한 채 이동 | 3D 부품 이동 또는 회전 다이얼 조작 |
| 빈 공간 끌기 | 3D 시점 회전 |
| 마우스 휠 | 확대·축소 |
| 우클릭 끌기 | 3D 시점 평행 이동 |

### 컴퓨터 조립

1. 구매 화면에서 모든 카테고리의 제품을 선택합니다.
2. `구매 확정 · 조립 시작`을 누릅니다.
3. 안내 패널에서 현재 부품의 두 가지 변형 중 구매한 모델을 확인합니다.
4. 작업대의 부품을 빛나는 장착 영역까지 끌어 놓습니다.
5. 14단계를 마치고 전원 인가 자체 검사를 확인합니다.

### 형광등·샤워기·서랍장

오른쪽 안내 패널의 조사와 선택을 순서대로 진행합니다. 작업을 멈춰야 하는 조건이 발견되면 강제로 계속하지 않고 전문가 점검 범위로 종료합니다. 이는 실패가 아니라 올바른 안전 판단입니다.

## 종료 조건과 결과

- **성공:** 선택한 실습의 모든 단계와 작동 검증을 완료합니다.
- **컴퓨터 점수:** 기본 100점에서 잘못 놓은 횟수당 8점이 차감되며 최저 60점입니다.
- **생활 실습 결과:** 구매 실수, 안전 절차 완료 여부, 호환 제품, 최종 작동 상태를 결과 화면에 표시합니다.
- **재도전:** 결과 화면에서 다른 실습을 선택하거나 같은 흐름을 다시 시작할 수 있습니다.

## 실행 방법

### 심사용 웹 실행

1. Chrome, Edge, Safari 최신 버전에서 플레이 URL을 엽니다.
2. 별도 회원가입, 설치, 결제 또는 유료 라이선스가 필요하지 않습니다.
3. 메인 화면에서 원하는 실습을 선택합니다.

권장 환경은 데스크톱 1280×720 이상과 마우스입니다. 모바일 화면도 지원하며 기기 성능에 따라 자동으로 2K 경량 모델을 불러옵니다. WebGL을 차단한 브라우저나 사내 보안 환경에서는 3D 화면이 표시되지 않을 수 있습니다.

### 소스에서 실행

```bash
git clone https://github.com/yunsulee2/bupum-jejak.git
cd bupum-jejak
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. 프로덕션 검증은 `npm run verify`로 실행합니다.

## 현재 범위

이 작품은 실제 작업을 대체하는 자격 교육이 아니라, 구매와 조립 전에 판단 과정을 연습하는 게임형 프로토타입입니다. 전기 배선·안정기 수리, 파손된 수도 부품 수리, 벽 재질을 확인할 수 없는 가구 고정처럼 전문가 판단이 필요한 작업은 실습 범위에서 의도적으로 제외했습니다.
